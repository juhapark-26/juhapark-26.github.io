01 / MOTIVATION

Why adapt before pooling?

Egocentric NIR eye videos contain weak physiological variation mixed with spatially uneven disturbances from eyelids, gaze, and headset motion.

Global spatial pooling compresses every eye-region location into one temporal descriptor. If temporal refinement happens only afterward, local trajectories that carry different levels of pulse information and corruption have already been mixed.

BEAT therefore applies one shared lightweight temporal operator to each bottleneck location first. The design preserves location identity during refinement while sharing weights across locations, keeping the parameter overhead small.

Design principle Refine local temporal trajectories, then aggregate them.

02 / METHOD

Two focused additions to a retained backbone

The Transformer-based backbone and waveform decoder remain in place. BEAT changes the bottleneck representation and its training objective.

A

Pre-pooling temporal adapter

Location-wise bottleneck refinement

The bottleneck tensor has shape B × 64 × 32 × 3 × 8. BEAT reshapes its 24 spatial positions into independent length-32 temporal trajectories, applies the same adapter to each trajectory, then restores the spatial grid for downstream pooling and decoding.

B × 64 × 32 × 3 × 8 → (B × 24) × 64 × 32 → B × 64 × 32 × 3 × 8
B

Depthwise temporal stack

Multi-scale temporal context

Four non-causal depthwise Conv1D layers use kernel size 3 and dilations [1, 2, 4, 8], yielding a 31-frame receptive field at the bottleneck resolution.

  • GroupNorm + SiLU
  • Pointwise GLU gating
  • Layer-scaled residual output
C

MPPL objective

Pulse-phase progression

Multi-Lag Pulse-Phase Progression Loss reconstructs a band-limited pulse, obtains analytic phase increments, and aligns prediction and target at lags {1, 2, 4}. Target-envelope confidence reduces the influence of ambiguous low-amplitude intervals.

Ltotal = Lwave + 0.1 Lspec + λ(t) LMPPL

04 / EFFICIENCY

Small parameter overhead

Location-wise processing shares one adapter across all spatial trajectories. It preserves local structure without creating a separate temporal module per location.

05 / INTERPRETATION

What the evidence supports

Supported

Location-preserving refinement

The component study supports the value of temporal adaptation before spatial pooling under the retained evaluation setting.

Supported

Complementary supervision

Adapter and MPPL together improve the aggregate HR metrics over either component alone in the reported snapshot.

Scope

Careful generalization

Current evidence is limited to egoPPG-DB. The non-causal adapter is not a strictly streaming implementation, and MPPL should not be interpreted as direct proof of high-motion robustness or beat-timing accuracy without dedicated evaluation.
