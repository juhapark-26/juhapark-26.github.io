# Juha Park — Academic Homepage

A responsive, dependency-free academic portfolio for GitHub Pages.

## Preview locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.

## Publish

Create a public repository named `juhapark-26.github.io`, push these files to its `main` branch, then enable GitHub Pages with **Deploy from a branch → main → /(root)**.

## Update content

- Profile and publication copy: `index.html`
- Styling: `assets/css/style.css`
- Filtering, theme, navigation, and copy-email behavior: `assets/js/main.js`
- Images: `assets/images/`
- BEAT project page: `projects/beat/index.html`
- Project-page styling: `assets/css/project.css`

No build step or external framework is required.
